# Martin Mwangi Ndegwa

**Data Scientist | Analytics | Data Engineer**

I build data systems and analytical solutions that turn complex, real-world data into reliable insights and decision-support tools — from storage engines and streaming pipelines to machine learning and geospatial intelligence.

## About

I'm completing an M.S. in Data Science, Analytics and Engineering at Arizona State University (3.94 GPA, May 2027), following a B.S. in Mathematics from Pwani University. The mathematics background shapes how I work: quantitative reasoning first, then the right tool for the problem.

I think about the full data lifecycle — ingestion → storage → modeling → transformation → distributed processing → streaming → analytics → machine learning → visualization → deployment — because I've built at both ends of it: statistical models on top, and the storage and streaming systems underneath.

## What I Work On

- **Data Engineering** — ETL/data pipelines, distributed processing, streaming systems, database design, containerization and orchestration
- **Data Science & Machine Learning** — regression, classification, clustering, ensembles, time-series, NLP/topic modeling, experimentation
- **Analytics** — statistical analysis, data validation, visualization, decision support
- **Applied AI** — LLM-powered assistants, AI agents, responsible-AI practices
- **Geospatial / Environmental Data** — satellite imagery, remote sensing, Earth Engine, environmental monitoring
